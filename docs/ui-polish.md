# 桌面便签 UI 优化

本轮以用户提供的便签截图为依据，保留奶油黄纸张与原生窗口按钮。

## 修改

- 将挤压正文的四行选项改为原生 Flyout；编辑、外观、管理分组，删除单独使用红色。
- 标题条统一为 44，底栏为 40；更多选项与格式工具使用图标，保留读屏名称和提示。
- 色点与选中环固定为圆形；按钮居中，统一悬停反馈。
- 调整正文留白、占位文案、文字层级。源码模式遵循便签字号。
- 格式工具在窄窗口中单行横向滚动，避免孤立按钮换行。
- 字号和透明度连续切换时更新选中态，不重建菜单，减少焦点丢失。

## 验证

- Release 构建及 macOS ARM64 发布成功，0 警告、0 错误。
- 28 项现有存储与集成检查通过；编辑器嵌入资源已重建。
- 独立数据目录内原生检查：280 宽窗口、换色、Markdown 标题与待办粘贴、保存、快捷键收起与展开、格式工具显隐、菜单收起操作。
- 菜单实际点击将字号设为 17、透明度设为 80%，持久化值匹配；连续切换时浮层保持打开，结束后恢复 15 / 100%。
- 窄窗口截图：`artifacts/ui-polish/narrow-window.png`。
- 菜单布局预览：`artifacts/ui-polish/data/popup.png`，来自同一原生 Flyout 的 RenderTargetBitmap。自动化工具的应用截图未包含单独的原生弹出窗口，因此这张图是控件渲染预览，不是桌面截图。临时渲染诊断代码已移除。
- 未执行 Windows 实机检查、完整读屏测试或本轮 Playwright 套件。
