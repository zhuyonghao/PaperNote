# 日夜主题与便签管理更新

- 便签卡片提供直接移入最近删除、恢复和更多操作；管理模式支持多选、全选、批量删除和批量恢复，永久删除仍需确认。
- 卡片右键和更多按钮使用统一的圆角操作面板，与桌面便签选项共享样式。
- 外观设置支持跟随系统、白天、黑夜；便签库、设置、文档、桌面纸张和编辑器同步更新。
- 桌面便签和 Markdown 文档支持只读沉浸阅读，隐藏格式与底部工具，保留退出入口；快捷键为 Command / Ctrl + Shift + R，Esc 退出。
- 空白桌面便签在关闭和退出应用时丢弃，不进入最近删除。仅含空白字符的新文档直接关闭；已有文件清空仍需决定是否保存。
- 读取编辑器失败会取消删除或退出，以免按陈旧内容处理空白便签。
